# ADR-0014: Многосерийные фильмы (MoviePart)

- **Status:** Accepted
- **Date:** 2026-07-30

## Context

Часть фильмов (особенно советская классика) выпускалась несколькими сериями одной работы: «Экипаж» (2 серии), «12 стульев» (2), «Мастер и Маргарита» (10). Это не TV-сериал и не франшиза: одно название, один год, одна оценка и обложка, но несколько файлов-частей.

`Release` уже описывает кодировку/файл. Нельзя перегружать его только номером серии без потери ясности: у одной серии может быть несколько релизов (1080p, 2160p). Нужен тонкий слой «серия» между `Movie` и `Release`.

## Decision

- Добавить `MoviePart` (`movieId`, `partNumber`, optional `title`) и nullable `Release.moviePartId`.
- `Movie.partCount` (nullable, >1) — денормализация для бейджа в каталоге без загрузки parts.
- Плоская связь `Movie.releases` сохраняется; фильтры каталога и tier не меняют форму запроса.
- Сканер: при маркере серии в имени файла группировать по `matchKey`, upsert `MoviePart`, создавать релиз с `moviePartId`. Файлы без маркера не автогруппируются.
- Редактор: секция «Серийность», `syncMovieParts` по образцу franchise slots (полная замена метаданных серий).

## Consequences

**Плюсы:** одна карточка фильма; чистое разделение серия vs релиз; обратная совместимость (`moviePartId = null`).

**Минусы:** после ручного `syncMovieParts` релизы не перепривязываются автоматически; `partCount` может расходиться, если не вызывать recompute/sync.

**Следующие шаги (не в scope):** привязка релиза к серии в редакторе релиза; фильтр каталога «многосерийные».
