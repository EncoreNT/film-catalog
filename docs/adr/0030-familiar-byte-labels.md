# ADR-0030: Привычные обозначения размеров в интерфейсе

- **Status:** Accepted
- **Date:** 2026-11-15

## Context

Пользователь попросил единые КБ/МБ/ГБ/ТБ во всём интерфейсе. Разные подписи
в каталоге, постерах и заполненности дисков мешают чтению. Уточнение о маркировке
диска не должно определять обозначения размеров во всём приложении.

## Decision

Все размеры в UI обозначаются Б/КБ/МБ/ГБ/ТБ. Общий `formatBytes`, включая режим
`binary`, сохраняет вычисления через 1024 и существующие правила округления.
Это пользовательское соглашение отображения, а не строгое применение SI.
Данные в байтах, ограничения загрузки, проверка свободного места и ввод ёмкости
с упаковки (через 1000) не меняются. Битрейт остаётся в kbps/Mbps, скорость
копирования — в МБ/с.

Это решение заменяет только правило подписей индикатора из ADR-0026. Прежние
ADR сохраняются как история решения; актуальные README и rules следуют этому ADR.

## Consequences

Единые подписи используются для файлов, постеров, дисков и ошибок загрузки.
Числа не меняются после обновления; миграций нет. Соглашение отличается от
строгого стандарта префиксов, что явно описано в общем форматтере.
