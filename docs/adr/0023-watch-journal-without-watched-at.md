# ADR-0023: Watch journal without watchedAt

- **Status:** Accepted
- **Date:** 2026-09-28
- **Supersedes:** ADR-0022 (denormalized `Movie.watchedAt`)

## Context

ADR-0022 завёл журнал `MovieWatch` и оставил `Movie.watchedAt` как последнюю дату, чтобы не трогать фильтр каталога. Отдельная колонка дублирует `max(watchedOn)`. Дата в форме редактирования фильма тоже писала в этот журнал и путала единственный источник: кнопку «Посмотрели».

## Decision

Колонка `Movie.watchedAt` удалена. История живёт только в `MovieWatch` (`id`, `movieId`, `watchedOn`). Один день на фильм по-прежнему `@@unique([movieId, watchedOn])`.

День появляется только из кнопки «Посмотрели». Форма редактирования дату не принимает.

Каталог:

- «просмотрен» = есть строка журнала или хотя бы одна оценка
- сортировка «дата просмотра» = последний `watchedOn` (считается при выборке списка, фильмы без журнала в конце)
- диапазон дат = последний день журнала попадает в интервал (`some` в диапазоне и нет дня позже верхней границы)

Слияние фильмов объединяет дни журнала. Выбора «какую дату оставить» нет.

## Consequences

**Плюсы:** одна таблица просмотров, без рассинхрона с колонкой на фильме.

**Минусы:** фильтр по диапазону — это последний просмотр, не «любой день из журнала попал в интервал».

**Follow-ups:** нет.
